### 1. 개요

---

반응형 자막은 자막의 글 길이에 따라 유동적으로 크기가 변화 할 수 있는 자막이다.
이런 자막은 편집자가 미리 설계한 정교하고 복합적인 디자인을 사용할 수 있기 때문에,
영상의 완성도를 높여준다.  

다만 모션 자막 템플릿 같은 경우 프로그램 구조적으로 빠르게 생성이 불가능한 장벽이 있다.  

일반적인 편집자가 많이 사용하는 프리미어 프로 같은 경우 그래픽으로 자막을 생성했을 경우 사전에 미리 디자인한 .prtextstyle 형태의 프리셋 템플릿을 이용해 드래그 앤 드롭으로 스타일을 일괄적으로 적용할 수 있다.  


![[Pasted image 20250707144134.png]]


하지만 에프터 이펙트로 생성한 자막이나, 프리미어 프로 내에서 생성한 "반응형 디자인 - 위치" 기능을 이용하여 제작한 자막은, 템플릿 구조적으로 소스의 텍스트나 좌표의 값을 참조하지 못하게 되어있기 때문에. 이를 직접 구현하기 위해서는 매 초마다 템플릿 소스를 불러와 자막을 입력해야 하는 일반 자막에 비해서 많은 수작업을 요구하게 되어있다.  


![[Pasted image 20250707144715.png]]


하지만 이런 비효율적인 면이 있지만 그럼에도 사용해야 하는 일이 있다.  
바로 합방과 같이 화자를 구분해야 하는 편집이 들어가게 될 때이다. 여러 오디오가 겹치는 합방 같은 경우 이를 구분해줘야 하는 필요가 있기 때문에 모션 자막 템플릿은 반 필수적이다.

### 4. 작업 프로세스

---

#### 1. 자동자막 생성 및 교정

영상의 컷 편집이 마쳤다면, 일반적으로 다음 작업은 자막 작업이 될 것이다.
이때 보통 자동자막 기능을 이용해 만드는데.  
이 때 프리미어 같은 경우에는 Transcript을 이용한 캡션, Vrew의 음성 분석, 프리미어 플러그인인 컷백이 있다 각자 장단점이 있으므로 성향에 맞는 방법을 선택하면 된다. 필자의 경우 Vrew의 음성 분석 기능을 주로 이용한다.  

![[Pasted image 20250714043423.png]]

이렇게 완성된 자막은 교정 과정을 거쳐 최종적으로 SRT파일로 만들어준다.  
srt 출력은 프리미어 같은 경우 caption 탭에 export기능을 통해 vrew는 내보내기 항목에서 형식을 선택할 수 있다.  

![[Pasted image 20250714044329.png]]

#### 2.자막 분활

자동으로 완성된 자막을 불러오면 다음과 같은 형태일 것이다.  

![[Pasted image 20250714045026.png]]

이중에서 작업하기 어려운 반복적으로 나오는 모션 템플릿 자막만 트랙을 추가하여 분리해준다  
이는 모션 템플릿은 적용할 자막은 트랙단위로 분리해야 관리하기 안전하기 때문이다.  

만일 이름이 들어간 자막이라면 등장 인물 수 만큼 트랙을 분리해 주면 된다.  
![[Pasted image 20250714044740.png]]

최종적으로 각 트랙을 프리미어 캡션의 export기능을 사용하여 트랙마다 srt파일로 자막을 분리해준다.  

![[Pasted image 20250714045935.png]]

> 이때 주의할 점은 절대 그래픽으로 업그레이드 해서는 안된다 캡션이 그래픽으로 변형되면 export를 통해서 srt파일을 출력할 수 없기 때문이다.  

#### 3. 자막 템플릿 제작

모션 자막 템플릿을 일괄로 적용시키기 위해서는 그 원본 파일이 필요로 한다.  
반응형 자막을 디자인 하기 위해서는 그에 따른 Expression 스크립트를 알맞게 적용시켜야 한다.  
이 때 컴포지션 길이는 만들고자 하는 영상의 길이만큼 늘리며 [모션 템플릿 출력용 자막](#모션 템플릿 출력용 자막) 폴더에 넣는다.  

> 만일 프리미어에 템플릿으로 등록하고자 한다면 이 컴포지션을 복사하여  
> [모션 템플릿 출력용 자막](#모션 템플릿 출력용 자막) 붙여 넣은후 30s로 컴포지션 길이를 설정하고  
> Essential Graphic 등록후 Export Motion Graphics Template하여 mogrt로 만들면 된다.  

![[Pasted image 20250714050521.png]]

최종적으로 Essential Graphic에 Source Text 등록하여 스크립트가 이름과 내용을 변경할 수 있도록 해줘야한다.  

![[Pasted image 20250714050735.png]]

#### 4. 출력용 컴포지션 생성

[자막](#자막) 폴더로 이동후 빈 컴포지션을 생성한다. 컴포지션의 길이는 편집하고 있는 영상의 길이만큼 하는 것을 추천한다.  
![[Pasted image 20250714051545.png]]

#### 5.스크립트 수정

코드 에디터 혹은 메모장으로 스크립트 파일을 열면 다음과 같을 것이다.  

![[Pasted image 20250714051834.png]]

이 스크립트에서는 1,2번 라인에 있는 두 가지 변수를 변경해주면 된다.  

**title** : 에프터 이펙트 파일에서 만든 적용할 자막 템플릿 컴포지션 이름  
**path** : 프리미어에서 출력한 자막 srt파일의 절대 경로  

![[Pasted image 20250714171318.png]]


두 가지 변수 변경후, 저장을 한다.  

에프터 이펙트로 돌아온 후, 자막이 출력 될 빈 컴포지션을 생성한다.  
길이(Duration)은 영상의 길이만큼 지정한다.  
![[Pasted image 20250714171513.png]]

빈 컴포지션을 생성하고 선택후
File > Scripts > Run Script File에서
위에서 저장한 스크립트 파일을 선택한다  

![[Pasted image 20250714171230.png]]

이 과정을 통해 자동으로 자막이 템플릿이 적용되어 레이어가 쌓이게 된다.  

![[Pasted image 20250714171706.png]]
